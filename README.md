## Portfólio - Desenvolvedor Full Stack

Este repositório reúne alguns dos principais projetos que desenvolvi com foco em prática, evolução técnica e aplicação de boas práticas de desenvolvimento.

Aqui você encontrará aplicações completas (front-end e back-end), explorando desde a construção de interfaces até a implementação de APIs, autenticação, validações e integração com serviços externos.

## 🔹 Front-end
JavaScript
TypeScript
React
Tailwind CSS
Consumo de APIs

## 📌 Objetivo

Este portfólio tem como objetivo demonstrar minhas habilidades como desenvolvedor, evidenciando:

Organização e estrutura de código
Boas práticas de desenvolvimento
Integração entre front-end e back-end
Resolução de problemas reais
Evolução contínua através de novos projetos
